# Викторина

Школьная викторина для урока: запускается на ноутбуке преподавателя, дети подключаются
с компьютеров класса по локальной сети. Интернет не нужен.

Четыре режима: **Классика**, **Захват территории**, **Башня**, **Побег**. Командная игра или
«каждый сам за себя», конструктор персонажей, реакции, звук, результаты в CSV для Excel.

## Запуск

Нужен **Node.js 20 или новее** (https://nodejs.org, версия LTS).

```bash
npm install
```

```bash
npm start
```

`npm start` собирает клиент, поднимает сервер и печатает адреса:

```
╔═══════════════════════════════════════════════╗
║  ВИКТОРИНА ЗАПУЩЕНА                           ║
║  Экран преподавателя (на этом ноутбуке):      ║
║     http://localhost:3000/teacher             ║
║  Адрес для детей:                             ║
║     http://viktorina.local:3000   ← основной  ║
║     http://192.168.1.42:3000                  ║
╚═══════════════════════════════════════════════╝
```

Другой порт: `npm start -- --port=3001` или переменная окружения `PORT`.

Для разработки с горячей перезагрузкой: `npm run dev` (клиент — http://localhost:5173,
сервер — :3000). Проверки: `npm run typecheck`, `npm test`.

При первом запуске Windows спросит разрешение для Node.js в брандмауэре —
**разрешите для частных сетей**.

## Как подключить детей

Страница ученика всегда одна и та же — корень сайта. Её можно открыть заранее, ещё до
начала урока: как только преподаватель создаст игру, у всех детей **сама появится кнопка**
«Присоединиться к тесту "…"». Код вводить не нужно.

Три способа открыть страницу, от лучшего к запасному:

1. **`viktorina.local:3000`** — сервер сам объявляет себя в сети по mDNS. Windows 10/11
   и macOS понимают такие имена без настройки.
2. **Ярлык** — при запуске сервер кладёт в папку `ярлыки/` файл `Викторина.url`.
   Скопируйте его один раз на рабочие столы классных ПК (или в `C:\Users\Public\Desktop\`).
   Рядом лежит `Викторина (по IP-адресу).url` — на случай, если mDNS в сети заблокирован.
3. **IP-адрес и QR-код** — всегда показаны на экране преподавателя в лобби. QR ведёт на
   IP-адрес, потому что телефоны на Android не всегда понимают имена `.local`.

Если mDNS не поднялся (роутер режет multicast), сервер не падает: пишет предупреждение,
а в лобби крупно показывает IP-адрес.

Код игры трёхзначный (100–999) — запасной путь для телефона или если в сети две игры.
Имя и персонаж ребёнка запоминаются в браузере: в следующий раз — одна кнопка, и он в игре.
Если у ребёнка пропал Wi-Fi или закрылась вкладка — он возвращается в ту же игру с тем же
счётом. Если закрылась вкладка преподавателя — игра ждёт 60 секунд; на странице
`/teacher` появится кнопка «Вернуться в игру».

**Если не подключается:** ноутбук и классные ПК должны быть в одной подсети; гостевой Wi-Fi
с «изоляцией клиентов» (AP isolation) не подойдёт — нужен обычный или проводной.

## Как положить тест

Раздел «Мои тесты» (`/teacher`). В зону загрузки можно перетащить **что угодно сразу**:
`.json` с вопросами, картинки (`.png .jpg .jpeg .webp .gif`), `.zip`-архив или целую папку.
Есть кнопка «Вставить JSON текстом» — если нейросеть ответила прямо в чат (обёртку
` ```json ` и текст вокруг уберём сами).

**Кнопка «Скопировать промпт для нейросети»** кладёт в буфер инструкцию: вставьте её в
ChatGPT или Claude, приложите свой Word/PDF/презентацию — и получите готовый JSON.
Текст промпта — в `client/src/data/aiPrompt.ts`.

Картинки привязываются к вопросам сами:

1. по явному полю: `"image": "вопрос3.png"`;
2. по номеру в имени файла: `3.png`, `вопрос3.jpg`, `q3.png`, `03.png` → вопрос №3;
3. по порядку: если номеров в именах нет, а картинок столько же, сколько вопросов с
   `"image": true`.

Перед сохранением показывается таблица сверки: можно перебросить картинку выпадающим
списком или перетащить непривязанную на нужную строку. Ничего не сохраняется до кнопки
«Сохранить тест». Картинки на сервере ужимаются до 1200 px и WebP.

Ошибки в JSON объясняются по-человечески, с номером вопроса, например:

> Вопрос 4: указано два правильных ответа, но тип вопроса «один правильный». Либо убери
> лишний `correct: true`, либо смени тип на `multiple`.

### Формат JSON

```json
{
  "title": "Строение скелета человека",
  "description": "Проверочная по биологии, 8 класс",
  "defaultTimeLimit": 20,
  "questions": [
    {
      "type": "quiz",
      "question": "Какая кость изображена на картинке?",
      "image": "1.jpg",
      "timeLimit": 20,
      "answers": [
        { "text": "Малоберцовая", "correct": false },
        { "text": "Бедренная", "correct": true }
      ]
    }
  ]
}
```

| `type` | Правило |
|---|---|
| `quiz` (по умолчанию) | ровно один верный, 2–4 варианта |
| `trueFalse` | ровно два варианта, один верный |
| `multiple` | 1–3 верных из 2–4; частичные баллы: очки × доля верных − штраф за лишние |

Необязательные поля: `image`, `timeLimit` (5–240 с, иначе `defaultTimeLimit`), `points`
(множитель очков вопроса 0–3, по умолчанию 1).

Готовый пример — папка `примеры/Демо-тест` и архив `примеры/Демо-тест.zip`. Этот же тест
автоматически появляется в «Моих тестах» при первом запуске.

## Как идёт игра

«Играть» → режим, команды (2–4, распределяются случайно при старте), время →
«Создать игру» → лобби с адресом, QR и кодом → «Начать игру».

Раунд: вопрос 2 с → приём ответов (таймер) → правильный ответ и диаграмма → событие режима
→ таблица лидеров. «Далее» — кнопкой или **пробелом**. Ученики отвечают мышью или
клавишами **1–4** (в `multiple` — отметить и Enter).

Очки: `1000 × (1 − время / лимит / 2)`, за неверный — 0; серия верных подряд даёт
×1.1 / ×1.2 / ×1.3 со 2-го, 3-го, 4-го ответа. Время засчитывается по часам сервера.

- **Классика** — топ-5 с перестановкой строк, пьедестал с конфетти.
- **Захват территории** — гекс-карта 14×10. За верный ответ 1 флаг, в серии от трёх — 3.
  После вопроса 15 с на расстановку: только рядом со своей территорией, чужой гекс — за два
  флага. Побеждает тот, у кого больше гексов. Без команд у каждого свой цвет; первый флаг
  ставится на любую свободную клетку.
- **Башня** — каждый верный ответ кладёт блок. Раз в N раундов (по умолчанию 5) монстр сносит
  2–3 верхних блока у лидера. Без команд видны топ-6 башен, остальные списком.
- **Побег** — 3 уровня. Верный ответ — шаг к двери, препятствие (яма/лужа) стоит лишнего хода.
  Робот идёт по часам уровня (они тикают, пока показан вопрос и идёт приём ответов) и
  подбирается ближе за неверные ответы. Кого догнал — выбывает до конца уровня. Уровень
  пройден, если до двери добежала половина игроков.

После игры: пьедестал, сводка (больше всех верных, самый быстрый ответ, самая длинная серия,
награда режима, трудные вопросы) и **«Скачать результаты (CSV)»** — UTF-8 с BOM,
разделитель `;`, два блока «Ученики» и «Вопросы». Все игры сохраняются: раздел
«История игр» позволяет скачать CSV задним числом.

Звук (тиканье на последних 5 секундах, верный/неверный ответ, фанфары) — только на экране
преподавателя, кнопка в шапке, выбор запоминается. При `prefers-reduced-motion` тряска,
параллакс и конфетти выключаются.

## Устройство проекта

```
shared/   общие типы, Zod-схемы теста, подсчёт очков, привязка картинок, гекс-сетка, команды
server/   Express + Socket.IO, игровой движок (src/game), режимы (src/modes),
          SQLite (data/app.db), mDNS и ярлыки (src/network.ts), CSV, фильтр имён
          (src/moderation/stoplist.ts — словарь можно дополнять)
client/   React 18 + Vite, Zustand, Framer Motion; «Побег» — PixiJS v8,
          «Захват» и «Башня» — SVG + Framer Motion
примеры/  демо-тест
```

Состояние игры живёт в памяти сервера, в SQLite пишутся только тесты и завершённые игры.
Счётчик ответов рассылается пачкой раз в 250 мс. Данные для бэкапа: `data/app.db` и
`data/uploads/`.

## Что не доделано и ограничения

- Звуки синтезируются в браузере (Web Audio API), а не берутся с freesound.org: так нет
  внешних файлов и вопросов к лицензии. Если хочется «живых» звуков — их можно добавить в
  `client/src/lib/sound.ts`.
- Персонажи, гербы, робот, монстр и фоны нарисованы с нуля в SVG/Pixi, ассеты Kenney и
  OpenGameArt не понадобились (см. `АССЕТЫ.md`).
- Редактора тестов в интерфейсе нет: тест меняется правкой JSON и повторной загрузкой
  («JSON» на карточке скачивает тест обратно).
- Нет авторизации — по условию задачи преподаватель тот, кто открыл `/teacher`.
- Проверено в Chromium (1366×768 у учеников, 1600×900 у преподавателя) на сценариях: все
  четыре режима, команды и одиночная игра, 1–8 учеников, переподключение ученика и
  преподавателя, загрузка zip/папки/картинок/текста. На реальной школьной сети с 30
  компьютерами не проверялось.
